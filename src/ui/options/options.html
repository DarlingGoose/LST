Use surrounding subtitle context

Sends nearby source lines around each new translation as reference, so pronouns, names, and sentence continuity survive. Context is reference-only; only requested cues are translated, and enabling it uses more tokens and may add latency.

How many nearby source lines travel with each request as reference.

Verify translations before caching

Rejects a model result that is not written in the target language instead of caching it. The line is sent once more on its own, then reported as failed. Detection compares writing systems, so it catches an untranslated or romanized line, but it cannot catch a wrong language that shares the target's writing system. Turn this off to cache every result the model returns.

Import subtitles

Attach a subtitle file to the episode you are watching, for a title the service does not subtitle: search Jimaku for the show, or bring a file you already downloaded. The file is kept on this device and becomes that episode's track. A file already written in your target language is shown as it is, without translating anything. A search also leaves a note about the show — what Jimaku held for it — that LST shows you when you open another episode of it, and the note is never something LST looked up on its own.

Local connection help

If Ollama refuses the extension request, allow browser-extension origins locally.

  1. Stop Ollama if it is already running.
  2. Start it with browser-extension origins enabled:
OLLAMA_ORIGINS=chrome-extension://*,moz-extension://* ollama serve
This changes only your local Ollama process. LST does not add a remote backend.Local only
