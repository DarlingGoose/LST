Local connection help

If Ollama refuses the extension request, allow browser-extension origins locally.

  1. Stop Ollama if it is already running.
  2. Start it with browser-extension origins enabled:
OLLAMA_ORIGINS=chrome-extension://*,moz-extension://* ollama serve
This changes only your local Ollama process. LST does not add a remote backend.Local only
