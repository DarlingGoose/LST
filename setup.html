Translate subtitles with your own models

LST adds a translation layer on top of the subtitle track the service already loads.

LST reads the timed text the service requests for a title, translates each line through the provider you choose, and draws the result over the player. The service's own subtitles, LST originals, and LST translations stay independent, so you can hide or show each layer while watching.

Local defaultNothing is sent to a developer-operated server.

Before you start

Have these ready for the next step.

  1. Ollama installed and running at http://localhost:11434.
  2. At least one translation model — LST can download one for you in the next step.
  3. A title on Netflix or Prime Video with a subtitle track you can turn on.
Prefer a cloud provider? DeepSeek and Gemini are optional and use your own API key.Optional

If Ollama refuses the extension request

Allow browser-extension origins on your own machine.

  1. Stop Ollama if it is already running.
  2. Start it with browser-extension origins enabled:
OLLAMA_ORIGINS=chrome-extension://*,moz-extension://* ollama serve
This changes only your local Ollama process. LST adds no remote backend.Local only

What happens next

Nothing changes on a service until you watch something.

  1. Open a watch page on Netflix or Prime Video and start playback.
  2. Turn on a subtitle track — LST needs the service to load the source text.
  3. Use the LST pill in the player to precompute an episode ahead of time or switch tracks.
