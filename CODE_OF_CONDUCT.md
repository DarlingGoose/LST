# Code of Conduct

## Our commitment

LST — Local Subtitle Translate is an open-source project, and everyone should be able to participate in a welcoming, respectful, and constructive environment.

We welcome contributors and users of all experience levels, backgrounds, languages, and perspectives.

## Expected behavior

Examples of behavior that helps create a positive community include:

- Being respectful and considerate in discussions, issues, reviews, and pull requests.
- Giving constructive technical feedback and assuming good intent.
- Being patient with contributors who are learning the codebase, browser-extension development, local AI tooling, or GitHub workflows.
- Respecting differing opinions, experiences, and approaches.
- Keeping discussions focused on improving LST and helping its users.

## Unacceptable behavior

Unacceptable behavior includes:

- Harassment, threats, discrimination, or personal attacks.
- Trolling, insulting or derogatory comments, or deliberately inflammatory behavior.
- Publishing another person's private information without explicit permission.
- Sexualized language or unwanted sexual attention.
- Repeatedly disrupting project discussions or ignoring reasonable maintainer requests.
- Any other conduct that would reasonably be considered inappropriate in a professional open-source community.

## Scope

This Code of Conduct applies to project spaces including GitHub issues, pull requests, discussions, code reviews, and other community spaces associated with LST.

## Enforcement

Project maintainers may edit, remove, or reject comments, commits, issues, pull requests, or other contributions that violate this Code of Conduct. Contributors who repeatedly or seriously violate it may be temporarily or permanently excluded from project spaces.

If you experience or witness unacceptable behavior, please contact the project maintainer privately using the contact methods available on the maintainer's GitHub profile. Please do not post sensitive reports publicly.

Reports will be handled as privately and fairly as reasonably possible.

## Attribution

This Code of Conduct is based on the principles of the Contributor Covenant, adapted for the LST project.
